# Portfólio de Gabriel Carvalho

Portfólio bilíngue em React, TypeScript, Vite e Tailwind CSS.

```sh
npm install
npm run dev
```

Abra `http://127.0.0.1:5173/pt` ou `/en`.

Validação: `npm run typecheck`, `npm run lint`, `npm run build`. Produto, direção visual, fontes e pendências estão em `PRODUCT.md`, `DESIGN.md` e `docs/`.
